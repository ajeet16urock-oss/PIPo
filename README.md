# PIPo
PIPo is a modular, high-density pocket terminal built around a dual-RP2350 and ESP32-C3 distributed architecture. Featuring a sliding 3" touch display inspired by classic handheld form factors, PIPo routes power, inputs, and high-speed data across a magnetic pogo-pin slider bus. It runs a barebones OS made by LVGL and MicroPython with a GUI .
